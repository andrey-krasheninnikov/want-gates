# Triage labels

| Role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs evaluation |
| needs-info | needs-info | Missing required information |
| ready-for-agent | ready-for-agent | Specified and ready for implementation |
| ready-for-human | ready-for-human | Requires maintainer work |
| wontfix | wontfix | Will not be implemented |

Use these exact labels when a workflow requests the corresponding role.
Blocking relationships determine whether a specified ticket can start.
