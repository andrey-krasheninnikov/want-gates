# Want Gates

[English](README.md)

Управление туннелями и маршрутизацией для существующего шлюза 3x-ui.

Want Gates направляет трафик VLESS-клиентов через исходящие VLESS-подключения или изолированные OpenVPN/Forti-подключения
по доменам, IP-адресам и CIDR. Подключения объединяются в группы компаний
с явно выбранным основным VPN и упорядоченными резервами.
Проверки целевого ресурса переключают данные и DNS вместе внутри группы.

## Состояние проекта

Rust-бинарник управляет группами, VLESS/OpenVPN/Forti-профилями, доменными/IP-правилами
и DNS подключений через Unix
socket. Preview и явный apply настраивают 3x-ui 3.8.5 с Xray 26.9.9.
TCP/UDP через IPv4/IPv6 проверяются отдельно; неподтверждённые сочетания
блокируются. Можно ограничить возможности подключения и проверить подготовленное
подключение без смены primary. См. [запуск службы](docs/service.md) и
[маршрутизацию, проверки и восстановление](docs/routing.md).

Поддерживаются ссылки `vless://` и полный outbound JSON. Импорт проверяет
структуру; apply проверяет панель и реальный трафик. Изолированный локальный
Linux/arm64-стенд проверяет две группы и сквозной VLESS ingress.
OpenVPN и Forti используют отдельную привилегированную службу для изоляции, штатной
авторизации и маршрутизации. См. [работу с OpenVPN](docs/openvpn.md) и [Forti](docs/forti.md).
Bootstrap, пакет skill и UI панели остаются в планах. Бинарный релиз не опубликован.

## Маршрутизация

1. Пользователь подключается к VPS через VLESS в 3x-ui.
2. Правило назначения выбирает группу.
3. Группа выбирает доступное подключение с нужными сетевыми возможностями.
4. Если подходящих подключений нет, трафик этой группы блокируется.

Трафик без подходящего правила выходит напрямую с VPS. Трафик выбранной
группы не переключается на прямой выход или VPN другой компании.

Группы работают одновременно. У подключения есть группа, имя, протокол,
состояние авторизации, DNS и подтверждённые возможности TCP/UDP и IPv4/IPv6.
Неоднозначные правила одинаковой специфичности отклоняются.

## Подключения и проверки

- Исходящий VLESS через Xray.
- Изолированный OpenVPN с сертификатами, паролем и поддерживаемыми штатными MFA/SSO-сценариями.
- Изолированный Forti через openfortivpn: пароль, сертификаты, OTP/push, cookie SSO и native SAML.
- В планах: WireGuard и NetBird.
- Импорт профилей и штатный вход, включая поддерживаемые MFA/SSO-сценарии.
- TCP, HTTP и HTTPS healthcheck, переключение на резерв и стабильный возврат внутри группы.

По умолчанию проверка выполняется каждые 30 секунд с timeout 5 секунд.
Три ошибки подряд означают недоступность; пять успешных проверок позволяют
вернуть новые соединения на восстановившийся VPN с большим приоритетом. Параметры
настраиваются для группы.

Одновременная работа изолированных аккаунтов NetBird требует runtime-проверки.
Forti поддерживает отдельно проверенные TCP/UDP через IPv4; IPv6 блокируется. Сохранение текущих сессий при смене пути или
перезапуске Xray не гарантируется.

## Планируемое управление и установка

Rust-бинарник предоставляет CLI и локальную systemd-службу с API через Unix socket.
Будущие изменения маршрутизации проходят предпросмотр и применяются отдельным действием.

Bootstrap установит Want Gates рядом с готовым совместимым 3x-ui. Базовая
версия: MHSanaei/3x-ui 3.8.5. Установщик сохранит чужие настройки панели
и проверит результат применения изменений.

Целевая платформа: Linux с systemd на `x86_64` и `aarch64`.
Автоустановка зависимостей планируется через `apt`, `dnf`, `pacman`
и `zypper`. Для остальных систем предусмотрены preflight и инструкции.
Совместимость каждой поддерживаемой среды должна быть подтверждена.

## Планируемые интеграции

Минимальный патч и сборка 3x-ui добавят раздел статуса и управления.
Интеграция Warp Terminal включает Workflows, Tab Config и MCP.
Локальные интеграции вызывают `wgates` на выбранном VPS через SSH.

Будущий пакет skill распространяется через существующий skills CLI:

```sh
npx skills@latest add andrey-krasheninnikov/want-gates
```

Это планируемая команда установки. Пакет skill ещё не опубликован.
Его установка не заменяет установку серверного бинарника.
